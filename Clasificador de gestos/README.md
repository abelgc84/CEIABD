# Clasificador de gestos con OpenCV y Machine Learning

Proyecto práctico de visión por computador y aprendizaje automático orientado a la clasificación de gestos de la mano aplicados al juego **piedra, papel o tijera**.

El objetivo del proyecto es construir un flujo completo de clasificación de imágenes, desde la captura o preparación de las muestras hasta el entrenamiento de un modelo de machine learning capaz de reconocer el gesto mostrado.

## Objetivo

Desarrollar un sistema capaz de identificar gestos de la mano correspondientes a:

- Piedra
- Papel
- Tijera

Para ello se utiliza procesamiento de imagen con OpenCV, extracción de características visuales mediante HOG y un modelo de clasificación SVM entrenado con scikit-learn.

## Tecnologías utilizadas

- Python
- OpenCV
- NumPy
- scikit-image
- scikit-learn
- Matplotlib
- Jupyter Notebook

## Conceptos trabajados

- Procesamiento de imágenes con OpenCV.
- Conversión a escala de grises.
- Redimensionado y normalización de imágenes.
- Extracción de características HOG.
- Preparación de datasets de imágenes.
- División de datos en entrenamiento y prueba.
- Entrenamiento de modelos de clasificación con SVM.
- Evaluación del modelo mediante métricas de clasificación.
- Predicción de nuevos gestos.
- Aplicación práctica al juego piedra, papel o tijera.
